Office of the Warden

To whoever runs this prison with friends,

The online mode works, until it doesn't. Four players at most. Big prisons drift out of sync, and when the game notices, it shows an error and throws the player out. The servers it talks to belong to someone else, and the multiplayer hasn't been touched since 2023.

pa-coop puts the server in your hands. It speaks the same language as the official one, so the game doesn't know the difference. The mod next to the game takes care of the rest: more players, and when the game reports a desync, the mod asks the host to resend the prison instead of dropping the player. It won't catch every case, but it is better than a kick.

Your saves and the game files stay as they are.

Install

  1. Windows (Steam or Epic)

    Download install-pa-coop.bat from the latest release and double-click it. It finds the game, copies three files next to it and asks one question: host or join.

  2. Host

    Pick "Host a game". Load a prison, then Menu > Go Online. The game starts the server for you and the router opens port 4533 (UPnP). The installer shows the address to give your friends.

  3. Join

    Pick "Join a friend" and type their address. In the game: Join Online Game, their prison is in the list.

  4. Linux (Steam)

    Same thing from a terminal, then add the launch option it prints:

    curl -fsSL https://raw.githubusercontent.com/fabienmillet/prison-architect-server/master/install/install.sh | bash

Router won't open the port? A VPN between friends (Tailscale, ZeroTier, NetBird) works too.

pacoop.txt

The only setting, next to the game:

# host
server=local

# join a friend
server=203.0.113.5

# or pick in the game's
# Region menu
servers=Us=pa.example.org, Local=local

Plain binary

Linux (amd64, arm64) or Windows, from the release page.

./pacoop-server -port 14533 -max-players 24
./pacoop-server -h

Incident reports

Questions people ask, filed and answered.

Incident #0041

Do my friends need the mod?

Yes. Every player installs it, it is what sends the game to your server. It is one double-click.

Incident #0042

Can I still play on the official servers?

Run the installer again and pick "Back to official multiplayer", or delete the three files.

Incident #0043

Does it touch my saves or the game?

No. It sits next to the game and only redirects online play. Saves and game files stay as they are.

Incident #0044

Do I need my own copy of the game?

Yes. pa-coop ships nothing from the game. Steam or Epic, every player needs a copy.

Incident #0045

What if a friend desyncs?

If the game detects it, the mod asks the host to resend the prison so the player can stay. A safety net, not a guarantee: some desyncs can still end the session.

Incident #0046

Mods and the game's DLC?

Same rules as the official co-op: the game disables mods online, and players should own the same DLC.
